# Design Spec: Osmo Sliders Sandbox Integration

This document outlines the design for integrating the Osmo Sliders (horizontal and vertical) into the Vite + React sandbox environment.

## Swapping Sliders
To match the design layout:
- **Horizontal Slider**: Testimonials.
- **Vertical Slider**: Latest Updates (Resources).

## Active State and Styling
- The active card in the vertical slider gets `data-vertical-slider-item-status="active"` and turns lime green with black text.
- The vertical slider resides in a centered circle container.
